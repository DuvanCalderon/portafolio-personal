# Flujo de trabajo: Notion → Codex → GitHub

1. Redactar y revisar contenidos en [Notion](https://app.notion.com/p/41d60fb53673807daa20dc2a61304335).
2. Actualizar textos y enlaces en `index.html`.
3. Para nuevos proyectos, añadir nombre, objetivo, contribución, tecnologías, demostración y repositorio.
4. Utilizar Codex con la skill `modern-web-guidance` para revisar HTML, accesibilidad, CSS responsive, rendimiento y SEO.
5. Probar en móvil, escritorio y teclado, y publicar los cambios aprobados en la rama `main`.
